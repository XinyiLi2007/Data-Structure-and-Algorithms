# W6-2 稀疏矩阵加法

## 1. 题目简介

给定两个行数、列数相同的稀疏矩阵，使用三元组表存储非零元素，计算两个矩阵的和。

每个三元组包含行号、列号和值，矩阵元素按照行主序排列，即先按行号递增，同一行内再按列号递增。

本题需要实现：

- `add()`：计算两个稀疏矩阵的和，并返回按行主序排列的三元组表。

## 2. 存储方式

使用三元组表存储稀疏矩阵，仅保存非零元素。

每个三元组包含：

- `row`：元素所在行。
- `col`：元素所在列。
- `value`：元素的值。

由于两个输入矩阵均已按照行主序排列，可以直接利用原有顺序完成加法，不需要还原为二维矩阵。

## 3. 实现方案

使用**双指针归并法**完成两个有序三元组表的合并。

分别使用下标 `i`、`j` 遍历矩阵 A、B，并根据当前三元组的坐标关系进行处理：

- **坐标相同：** 将两个元素的值相加；若结果为 0，则不保存该元素。
- **A 的坐标更靠前：** 将 A 的当前元素加入结果，并移动 `i`。
- **B 的坐标更靠前：** 将 B 的当前元素加入结果，并移动 `j`。
- **其中一个矩阵遍历结束：** 将另一个矩阵剩余的元素依次加入结果。

## 4. 核心算法思想

本题的关键是利用三元组表已有的有序性，将矩阵加法转化为两个有序序列的归并过程。

比较坐标的两种方法：
- **直接比较：** 先比较行号；行号相同时，再比较列号。这样可以直接确定两个元素在行主序中的先后关系。（推荐，直接，可读性强）
- **转化成线性进行比较：** 把坐标映射成行号乘上列数加上列号进行比较。（巧妙，但有可能产生溢出）

由于每次操作至少移动一个指针，每个输入元素至多被处理一次，因此能够在线性时间内完成计算。

## 5. 复杂度分析

设两个矩阵的非零元素个数分别为 \(t_A\)、\(t_B\)。

| 操作 | 复杂度 |
|---|---|
| 时间复杂度 | \(O(t_A+t_B)\) |
| 结果数组空间复杂度 | \(O(t_A+t_B)\) |
| 额外辅助空间复杂度 | \(O(1)\) |

结果数组按照两个输入矩阵的非零元素总数分配空间；最终结果的非零元素个数不会超过该总数。

## 6. 边界情况与注意事项

- 两个矩阵均为空矩阵的三元组表。
- 某个矩阵没有非零元素。
- 两个矩阵存在相同坐标，且对应元素之和为 0。
- 两个矩阵的非零元素坐标完全不同。
- 结果中的三元组必须保持行主序。
- 比较坐标时建议直接比较行号和列号，避免线性化坐标时出现整数溢出。
- 注意结果数组的动态内存分配与释放。

## 7. 学习总结

本题的核心是利用已有的有序存储结构完成双指针归并。

通过本题，进一步理解了：

- 如何利用有序性降低算法复杂度。
- 如何使用双指针处理两个有序序列。
- 如何处理相同位置元素相加后变为 0 的情况。
- 如何在不构造完整二维矩阵的前提下完成稀疏矩阵运算。
