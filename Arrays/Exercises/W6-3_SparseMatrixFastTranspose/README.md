# W6-3 稀疏矩阵快速转置

## 1. 题目简介

给定一个$m×n$的稀疏矩阵，使用三元组表存储其非零元素，实现矩阵的快速转置，并输出转置后的三元组表。

转置后，原矩阵中位置为 $(i,j)$ 的元素变为 $(j,i)$，元素值保持不变。

本题需要实现：

- `transpose()`：返回转置后的稀疏矩阵，且三元组按照行主序排列。

## 2. 存储方式

使用三元组表存储矩阵的非零元素，每个三元组包含行号、列号和值。

输入三元组已经按照行主序排列。转置后，原矩阵的列号变为新矩阵的行号，因此不能简单地交换每个三元组的行号和列号后，就认为结果仍然有序。

## 3. 实现方案

本题采用**快速转置算法**，利用预处理数组确定每个元素在转置矩阵中的存储位置。

主要步骤如下：

1. **统计各列非零元素个数：** 遍历原矩阵，记录每一列包含的非零元素数量。
2. **计算各列的起始位置：** 将列元素个数转换为转置矩阵中对应行的起始下标。
3. **直接放置元素：** 遍历原三元组表，根据原元素的列号查找其在转置矩阵中的位置，交换行列坐标并复制元素值。
4. **更新下标：** 每放置一个元素，就将对应列的下一个可用位置向后移动。

## 4. 核心算法思想

转置后，原矩阵的第 $j$ 列会成为新矩阵的第 $j$ 行。

因此，只要提前统计原矩阵每一列的非零元素数量，并计算这些元素在结果数组中的起始位置，就可以直接将元素放到正确的位置。

由于原矩阵的三元组按照行主序排列，同一列中的元素会按照原行号递增的顺序被访问，因此放置到对应新行后的元素也会按照新列号递增的顺序排列。

这种方法避免了逐列反复扫描原矩阵，从而提高转置效率。

## 5. 复杂度分析

设原矩阵的行数为 \(m\)、列数为 \(n\)，非零元素个数为 \(t\)。

| 操作 | 复杂度 |
|---|---|
| 时间复杂度 | \(O(n+t)\) |
| 结果数组空间复杂度 | \(O(t)\) |
| 额外辅助空间复杂度 | \(O(n)\) |

其中，列计数与起始位置数组需要 \(O(n)\) 的空间，转置结果需要保存全部 \(t\) 个非零元素。

## 6. 边界情况与注意事项

- 矩阵没有非零元素，即 \(t=0\)。
- 某些列没有非零元素。
- 矩阵为非方阵，转置后行数与列数需要交换。
- 转置结果必须按照新矩阵的行主序排列。
- 注意区分列中元素的数量与该列在结果数组中的起始下标。
- 动态分配的结果数组需要由调用方负责释放。

## 7. 学习总结

本题的核心是通过预处理数组确定转置后各元素的存储位置。

通过本题，进一步理解了：

- 如何利用列计数和前缀和思想进行位置预处理。
- 如何避免重复扫描三元组表。
- 如何在一次遍历中完成元素的转置与有序存储。
- 如何分析快速转置算法的时间与空间复杂度。
